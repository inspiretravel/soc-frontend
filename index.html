How it works

Bait, record, explain. That's the whole idea.

02

About the builder

Ten years of enterprise ticket triage, pointed at security.

10 years of SAP ERP incident ticketing — priority triage, SLA management, escalation under pressure. Those workflows map directly to SOC work. This project demonstrates MITRE ATT&CK knowledge applied to real defensive telemetry, not just reading logs.

What it does

  • Real honeypot telemetry (Cowrie SSH/Telnet, Dionaea multi-protocol)
  • MITRE ATT&CK mapping — the full Enterprise technique set
  • ACSC Essential Eight, NIST CSF 2.0 and ISO/IEC 27001:2022 linkage
  • Priority queue, written cases, framework-mapped assessment

Tech stack

  • Python 3.11 · Flask 3.0 · SQLite
  • MITRE ATT&CK STIX (live from MITRE's GitHub)
  • Claude API for triage prose — server-side only, keys never in the browser
  • This front end: static HTML/CSS/JS on Cloudflare Pages · D3 globe

Key features

  • Every case sentence traceable to grouped raw events
  • Case management with analyst notes (backend)
  • Server-side credential proxy — the public site holds no secrets
  • Read-only public API; attacker-derived text always escaped
